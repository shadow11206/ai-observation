# 观点更新日志使用说明

> 这里存放的是你对 AI 行业关键问题的**实时判断**，不是文章收藏，不是资料整理。

## 使用规则

1. **每个文件对应一个核心问题**，文件名用英文（便于链接引用）
2. **最顶部的"当前判断"是你现在的立场**，任何时候打开这里都能快速获得答案
3. **每次有新信息影响你的判断，就在"更新记录"里追加一条**，时间倒序
4. **信心等级**：★ = 猜测，★★★ = 有依据，★★★★★ = 非常确定
