# 核心问题：AI Agent 真正落地的时间线？

> 建立日期：2026-03-24
> 最近更新：2026-04-08

---

## 🟡 当前判断（截至 2026-04-08 v2）

分水岭不是「重复性 vs 复杂性」，而是**「工作成果能否被最终买家直接验收，不需要专业人士背书」**。

- 能被直接验收的成果型工作（如 NDA 起草、保险询价、合同套语）→ Autopilot 可以今天起步
- 需要专业人士背书的判断型工作（如战略决策、复杂谈判、危机公关）→ AI 目前做不到，监管也不允许

这比「高判断力 vs 低判断力」更精确，也解释了为什么 Harvey 能到 $110 亿估值：它卖的是最终客户可以直接验收的法律工作成果，而不是卖工具给律师。

信心：★★★★（验收阈值框架有一手数据支撑，但管理咨询等高判断力赛道仍 TBD）

### 2026-03-24 | 首次建立判断

- **来源**：Barry Zhang（Anthropic）的 Agent 设计原则分享 + ai-insight 项目中的 Agent 调研
- **触发信息**：Agent 在生产环境仍然是少数，大多数场景还处于 demo/内测阶段
- **判断**：
  - L1 实践者普遍反馈：垂直 Agent 有真实使用案例，但定制程度很高
  - 通用 Agent（如 Devin）的实际留存率低，用户主要用于边缘任务
  - 时间线估计：垂直场景 2025-2026 年部分规模化，通用 2028+ 年
- **信心**：★★★☆☆
