### 7. 接入 OpenRouter 模型调用排行榜

**背景：** 哥提出把 https://openrouter.ai/rankings?view=day 的 Top 10 数据集成到日报快照。

**可行性调研：**
- OpenRouter 用 Next.js RSC 流，无公开 REST API
- 通过 `GET https://openrouter.ai/rankings?view=day&_rsc={token}` 带特定 header 即可拿到 442KB 完整数据流
- 数据在第 47 行，字段：`model_permaslug` / `total_prompt_tokens` / `total_completion_tokens` / `count` / `change`（环比变化）

**实现：** `fetch_snapshot.py` 新增 `_fetch_openrouter_ranking()`：
- 随机生成 `_rsc` token，模拟浏览器请求
- 逐字符括号匹配提取 `rankingData` 数组（防正则贪婪失效）
- 按模型聚合多 variant 行，取 `total_tokens` 排序 Top 10
- 去掉末尾日期后缀（`-20260318`），处理 `:free` variant 后缀
- 存入 `snapshot.openrouter_ranking`

**前端（`report.js`）：**
- 在 GitHub Trending 下方新增「OpenRouter · 模型调用排行」板块
- 展示：排名 / 模型名 / org / token量 / 环比变化（绿色↑红色↓）
- 右上角「查看完整榜单 →」链接跳转原站

**测试结果（本地验证，与浏览器数据完全一致）：**

## 踩坑记录（追加）

3. **RSC 数据流解析不能用正则 `.*?`**：`rankingData` 数组超长，非贪婪正则无法匹配完整数组。改用逐字符括号深度计数来定位数组边界，稳定可靠。
4. **回滚后要立刻修复数据文件**：哥回滚操作导致 `2026-03-28.json` 的 `top_items` 为空（数据被塞在 `raw_content` 字段）。正确做法是从 `raw_content` 提取内嵌 JSON 覆盖外层空字段，同时修复 `generate_daily.py` 的 JSON 提取正则防止复现。
5. **JS 语法错误必须在 push 前验证**：多次出现 `_removed()` 残留函数导致模板字符串未闭合，页面卡死在加载。规范：所有 JS 改动必须先跑 `node --check`，通过后再 push。
