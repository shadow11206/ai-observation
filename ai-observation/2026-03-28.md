### 7. OpenRouter 模型调用排行榜接入

**背景：** 想在快照板块加 OpenRouter 实时模型调用排行，但要求：不开机、不调浏览器、与日报一起自动生成。

**技术调研：** 浏览器 Network 面板确认 OpenRouter Rankings 页面用 Next.js RSC 流传输数据，`GET https://openrouter.ai/rankings?view=day&_rsc=随机token` + 特定 headers 即可拿到完整数据，无需 API Key 和浏览器。

**实现：**

`scripts/fetch_snapshot.py` 新增 `_fetch_openrouter_ranking()` 函数：
- 带 RSC 相关 headers 发 GET 请求
- 逐字符提取 `rankingData` 数组（防正则贪婪失效）
- 按 `model_permaslug` 聚合 prompt + completion tokens
- 排序取 Top 10，输出字段：`name / org / total_tokens_str / change（百分比）/ url`
- 失败静默降级，不影响其他板块

`ui/scripts/report.js` renderSnapshot 新增 OpenRouter 区块：
- 标题右侧附「查看完整榜单 →」链接
- 每行：排名 / 模型名 + org / token 量 / 环比（绿涨红跌）

**验证：** 本地测试返回 367 条原始数据，Top 10 与浏览器截图完全一致。

## 踩坑记录

1. **改了数据层要主动检查展示层**：升级完 `.md` 文件后没有主动发现前端没有联动，等哥反馈才改。下次改完数据，立刻检查所有前端展示。
2. **全站 hardcoded 数值要 grep 全局找一次**：修 stats-bar 时漏掉了 feature-card 里同一数字的另一处硬编码。改数值前先 `grep -r "60+"` 把所有出现位置找全再统一替换。
3. **回滚后要核对 JSON 数据完整性**：哥回滚代码后，`2026-03-28.json` 的 `top_items` 变成空数组，`raw_content` 里有完整数据没被解析。下次回滚后立刻检查 JSON 数据字段是否完整，不只看文件存在。
4. **multi_replace_in_file 会产生残留垃圾代码**：之前某次 multi_replace 操作留下了 `_removed()` 函数（含未闭合 template string），导致 JS 加载卡死。每次 JS 改动后用 `node --check` 验证语法再 push。
5. **RSC 数据行的前缀格式固定**：OpenRouter RSC 每行格式为 `hex前缀:JSON内容`，用正则 `^[0-9a-f]+:(.*)` 提取，不能直接 json.loads 整行。
