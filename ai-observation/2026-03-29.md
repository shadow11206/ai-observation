### 2. 修复 fetch_snapshot.py 被误删

**现象：** 上一个 commit 统计显示 `2 files changed, 5 insertions(+), 124 deletions(-)` ——`ui/report.html` 只改了 1 行，但 `fetch_snapshot.py` 被删了 124 行。

**根因：** `replace_in_file` 操作时匹配到了 `fetch_snapshot.py` 里的某段内容并错误覆盖，`_fetch_openrouter_ranking()` 函数完整丢失。

**修复：** 从 git 历史恢复：
```bash
git show HEAD~1:scripts/fetch_snapshot.py > /tmp/fetch_snapshot_backup.py
cp /tmp/fetch_snapshot_backup.py scripts/fetch_snapshot.py
```
验证语法 OK（337行，函数完整）后 push。
