# 开发日志 · 2026-03-26

## 今日完成

### 1. 苹果风格静态网站搭建（核心）

**背景：** 日报系统数据已通 Actions 自动生成，但只有 Markdown 文件，没有可视化展示界面。决定从零设计一套苹果风格静态网站。

**设计原则：**
- 苹果 Human Interface Guidelines 风格：白底/浅灰背景、SF Pro 字体栈、圆角卡片、无装饰主义
- 纯静态：HTML + CSS + 原生 JS，无框架，GitHub Pages 直接托管
- 移动端优先响应式布局

**新增文件（`ui/` 目录）：**

| 文件 | 说明 |
|------|------|
| `ui/index.html` | 首页：项目介绍 + 快速入口卡片 |
| `ui/daily.html` | 日报列表页 |
| `ui/tracking.html` | 追踪体系页（人物/公司/信息源 Tab 切换） |
| `ui/scripts/main.js` | 首页逻辑 |
| `ui/scripts/daily.js` | 日报列表动态加载 |
| `ui/styles/main.css` | 全站通用样式（CSS 变量 + 苹果色彩系统） |

**核心设计要素（`main.css`）：**
```css
--accent: #007AFF;          /* 苹果蓝 */
--bg-primary: #F5F5F7;      /* 苹果浅灰背景 */
--text-primary: #1D1D1F;    /* 深灰文字 */
--radius-lg: 18px;          /* 大圆角卡片 */
```

### 2. 从 ui 分支迁移到 main 分支

**背景：** 最初错误地在独立 `ui` 分支上开发，GitHub Pages 配置更复杂。

**迁移步骤：**
1. 在 `main` 分支创建 `ui/` 目录，把 `ui` 分支内容全部拷入
2. GitHub Pages 设置：Source → `main` 分支 → `/ui` 目录
3. 本地删除 `ui` 分支

### 3. 根目录跳转设置

**问题：** 访问 `shadow11206.github.io/ai-observation/` 会显示旧版 Jekyll 页面，不是新 UI。

**修复：** 根目录新增 `index.html`，写入 `<meta http-equiv="refresh" content="0;url=./ui/">` 实现自动跳转。
