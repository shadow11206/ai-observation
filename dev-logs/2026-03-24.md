### 2. 日报自动生成工作流搭建

**核心逻辑：** GitHub Actions 每天 09:00 UTC+8 触发 → `fetch_rss.py` 抓取 RSS 信息 → `generate_daily.py` 调用 AI 生成日报 → 自动 commit + push

**关键文件：**
- `scripts/config.yaml`：信息源、追踪人物、AI 配置
- `scripts/fetch_rss.py`：RSS 抓取 + 去重 + 按时间过滤
- `scripts/generate_daily.py`：调用 DeepSeek API 生成 Markdown 日报
- `scripts/prompts/daily_report.txt`：日报生成 prompt
- `.github/workflows/daily-report.yml`：Actions 工作流定义

**GitHub Secrets 配置：**
- `AI_API_KEY`：DeepSeek API Key
- `AI_API_BASE`：`https://api.deepseek.com`

### 4. Actions 调试

**问题 1：** `openai` + `httpx` 版本不兼容
- 报错：`httpx` 版本过低与 `openai>=1.52.0` 冲突
- 修复：`requirements.txt` 锁定 `openai>=1.52.0` + `httpx>=0.28`

**问题 2：** Actions 步骤版本过旧（`actions/checkout@v2`）
- 修复：升级到 `actions/checkout@v4` + `actions/setup-python@v5`，添加 Secret 检查步骤防止空 Key 静默失败
