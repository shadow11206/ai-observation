## ✅ 完成内容

### 1. OpenRouter 排行榜数据接入

**做了什么**：实现通过 Python 脚本直接抓取 OpenRouter RSC 接口数据，解析 Top 10 模型并存入 JSON 快照。

**方案**：`GET https://openrouter.ai/rankings?view=day&_rsc=随机token`，加 `RSC: 1` / `Next-Router-State-Tree` headers，逐字符提取 `rankingData` 数组（防止正则贪婪失效）。

**产出**：`fetch_snapshot.py`，367 条原始数据，Top 10 与浏览器完全一致

### 2. key_data prompt 用"禁止规则"优化

**做了什么**：原版 prompt 只说"要什么"，输出出现"大型强子对撞机（LHC）""Coding plan 售罄"等无意义内容。新版加三条禁止规则，输出质量大幅提升。

**经验**：prompt 工程中「禁止做什么」和「要做什么」同等重要

### 3. 数据快照 UI 改版：双列 → 单列

**做了什么**：原双列空洞感强（GitHub 一栏经常空），模型名截断看不懂。改为单列，每行显示模型短名 + NEW/连续上榜 badge + org + 中文类型标注。

## ❌ 被纠正的地方

### 1. JSON 回滚后没主动验证数据完整性

- 哥回滚代码后，`2026-03-28.json` 的 `top_items` 是空数组，`raw_content` 里有完整数据没被解析
- 经验：回滚后立刻用 `python3 -c "import json; print(len(json.load(open('xxx.json'))['top_items']))"` 验证，不要等哥打开页面发现"没内容"

### 2. git push 反复失败（重复踩坑）

- 改多个文件时没先 `git status` 确认工作区干净，stash 后还有 unstaged changes 导致 rebase 失败

## 🔧 踩坑

### 1. multi_replace_in_file 留下残留垃圾代码

- 留下 `_removed()` 函数（含未闭合 template string），导致 report.js 加载卡死
- 表现：页面一直"加载日报中"，无报错
- 诊断：`node --check ui/scripts/report.js`
- **规则：每次修改 JS 文件后必须 node --check 再 push**

### 2. RSC 数据行有 hex 前缀

- 格式：`25:[...]`，不能直接 `json.loads(line)`
- 解法：`re.match(r'^[0-9a-f]+:(.*)', line, re.DOTALL)` 提取
