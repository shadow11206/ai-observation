## 结论摘要

中国多模态赛道的竞争已从"能不能做到"进入"以多低价格做到"的第二阶段。以 Qwen3.5-Omni 为代表，中国厂商已实现与 Gemini 顶级模型在多项评测上的正面竞争，且定价低至其 1/10 以下。这场价格战的深远影响不在于谁赢谁输，而在于它正在重塑全球 API 市场的价格基准——一旦 Gemini 水平的多模态能力的"合理价格"被 0.8元/百万 token 锁定，整个行业的盈利预期将被系统性压低。与此同时，OpenRouter 榜单显示中国厂商（小米 MiMo、StepFun、MiniMax）已在全球开发者市场占据前四席中的三席，这不再是"追赶者"的叙事，而是真实的市场份额夺取。

---

## 核心发现

### 1. Qwen3.5-Omni：性能已到位，定价是杀手锏

**发现**：阿里 Qwen3.5-Omni-Plus 在 215 项音频/音视频评测中取得 SOTA，通用音频理解、推理超越 Gemini-3.1 Pro，音视频理解整体达到 Gemini-3.1 Pro 水平。

**关键数据**：
- 文本/图片/视频输入：**0.8元/百万 token**（≤128k 场景）
- 音频输入：4.96元/百万 token
- 对比 Gemini-3.1 Pro：Qwen 文本输入定价约为其 **1/10 以下**

**判断**：性能接近，价格差了一个数量级。这不是"够用就行"的低价替代，而是在旗舰能力上的正面竞争。对企业开发者而言，切换成本几乎为零，理由却非常充分。

*来源：[36氪/智东西 2026-03-31](https://eu.36kr.com/zh/p/3746281380348680)*

**发现**：截至 2026-03-31，全球开发者最活跃使用的前 4 名模型中，有 3 个来自中国。

**关键数据（OpenRouter 实际调用量排名）**：

**判断**：这是真实的市场渗透，不是 benchmark 游戏。小米 MiMo 以 713B token 调用量断档式领先，说明中国模型在全球开发者市场已建立实质性用户基础。MiniMax 月增 11.4% 的势头需要持续关注。

*来源：项目日报 OpenRouter 快照 2026-03-31*

### 3. 技术路径：Thinker-Talker 分工架构 + MoE 是成本优势的底层来源

**发现**：Qwen3.5-Omni 延续 Thinker-Talker 分工设计，并将两者全部升级为 Hybrid-Attention MoE（混合注意力 MoE），同时引入 ARIA（自适应速率交错对齐）技术解决流式语音 token 对齐问题。

**判断**：MoE 架构是中国厂商实现低成本高性能的关键——推理时只激活部分参数，大幅降低单次推理成本，这是定价低至 0.8元/百万 token 的技术支撑，而非补贴烧钱。这个技术路径与 DeepSeek-v3 系列一脉相承，说明中国厂商在 MoE 工程化上已形成体系性积累。

*来源：[36氪/智东西 2026-03-31](https://eu.36kr.com/zh/p/3746281380348680)*

---

### 4. 多模态赛道的新战场：全模态 = 视频理解 + 实时语音 + 端到端交互

**发现**：Qwen3.5-Omni 的差异化能力集中在：支持超过 10 小时音频输入、400 秒 720P 视频输入、语义打断、音色克隆、39 种方言/74 种语言；字节豆包 Seed1.5 同期新增多模态推理；HF Trending 榜前 8 中有 4 个是多模态理解模型（其中 3 个基于 Qwen3.5 系列）。

**判断**：多模态的战场不再是"能不能理解图片"，而是"能不能处理实时流式的视频+语音"。这个能力直接对应的场景是智能客服、实时翻译、视频内容审核——都是有明确付费意愿的 B 端场景。谁先做到又便宜，谁就能拿下这些场景的 API 份额。

---

### 5. 中国模型生态的隐藏信号：Qwen 成为开源蒸馏的基础设施

**发现**：HF Trending 前 8 中，有 3 个是基于 Qwen3.5 的蒸馏/微调模型（`Qwen3.5-27B-Claude-4.6-Opus-Reasoning-Distilled`、`Qwen3.5-35B-A3B-Uncensored` 等），下载量合计超过 100 万次。这些模型由第三方用 Claude/GPT 的推理能力蒸馏 Qwen 底座而来。

**判断**：Qwen 系列不仅在 API 市场竞争，还成为全球开源社区蒸馏实验的主要底座。这意味着阿里在技术生态上的渗透深度超出官方数据所呈现的范围。Qwen 的开源策略正在形成类似 Meta LLaMA 的生态飞轮，但加上了"旗舰能力够用"的优势。

*来源：项目日报 HF Trending 快照 2026-03-31*
